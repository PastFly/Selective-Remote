# Участие в разработке Selective Remote

Спасибо за желание помочь проекту.

## Перед началом

1. Создайте issue с описанием ошибки или предлагаемого изменения.
2. Не публикуйте пароли, приватные ключи, реальные адреса серверов и полные
   журналы, содержащие инфраструктурные данные.
3. Для уязвимостей используйте порядок из [SECURITY.md](SECURITY.md), а не
   публичный issue.

## Локальная проверка

```bash
brew install freerdp sdl3
swift test
swift build
bash -n scripts/build_app.sh
bash -n scripts/build_and_install.sh
```

Полная сборка приложения выполняется командой:

```bash
./scripts/build_app.sh
```

## Pull request

- создавайте отдельную ветку для одного логического изменения;
- добавляйте тест на исправленную ошибку, когда это возможно;
- не включайте `.build`, `dist`, DMG, журналы и настройки пользователя;
- опишите, что изменено и как это проверялось;
- сохраняйте интерфейс на русском языке или обновляйте все связанные строки.

Отправляя изменение, вы соглашаетесь распространять свой вклад на условиях
[MIT License](LICENSE), а изменения стороннего кода — на условиях его лицензии.
