# Сборка Selective Remote 0.19.0

Архив с исходниками создаёт отдельный каталог
`SelectiveRemote-0.19.0-source-public`, не затрагивая прежние
распаковки.

```bash
cd ~/Downloads
unzip -q SelectiveRemote-0.19.0-source-public.zip
cd SelectiveRemote-0.19.0-source-public
./scripts/build_and_install.sh
```

Скрипт собирает приложение, сохраняет установленную ранее версию в Корзине,
устанавливает новую в `/Applications` и запускает её.

После успешной сборки будут созданы:

- `dist/Selective Remote.app`;
- `dist/SelectiveRemote-0.19.0-arm64.dmg` на Apple Silicon;
- `dist/SelectiveRemote-0.19.0-arm64.dmg.sha256`.

Откройте DMG и перетащите **Selective Remote** в `Applications`.
Пакет, интерфейс и системные диалоги используют одно имя — **Selective Remote**.

## Быстрая проверка RDP

1. Выберите существующий RDP-профиль.
2. Убедитесь, что тип подключения — **RDP**.
3. Для проверки смешанной плотности выберите внешний Full HD и встроенный
   Retina-дисплей. В полноэкранной сессии изображение должно заполнять оба экрана.
4. В разделе **Устройства и звук → Клавиатура** оставьте включённым
   **Command работает как Ctrl** и проверьте ⌘C/⌘V. Правый Command при этом
   может оставаться клавишей Windows.
5. В разделе **Клавиатура** оставьте включённым **Fn переключает язык Windows**,
   откройте RDP и одиночно нажмите Fn. Windows должна получить Win+Space.
6. Проверьте отказ в доступе к микрофону или камере: RDP должен подключиться,
   отключив только соответствующее устройство.
7. В разделе **Дисплеи → Масштаб и окно** проверьте режим
   **Окно · менять разрешение**: после resize разрешение Windows должно измениться.
8. В работающей сессии откройте меню Selective Remote в строке macOS и нажмите
   **Открыть панель управления**; проверьте Windows, Alt+Tab и Print Screen.

Профили старых версий автоматически считаются RDP, дополнительных действий не
требуется.

## Быстрая проверка SSH

1. Нажмите **+ → Новое SSH**.
2. Укажите hostname, пользователя и порт.
3. Без выбранного ключа нажмите **Открыть SSH** — откроется вкладка
   **Терминал** внутри Selective Remote. Внешние приложения не запускаются.
4. Проверьте интерактивный запрос host key/пароля и выполните несколько тестовых
   команд. При вводе `nano /e` или `systemctl re` должны появиться варианты из
   встроенного каталога даже при пустой истории.
5. Нажмите кнопку истории в панели терминала. Проверьте вкладки **История** и
   **Общие команды**, поиск, подстановку, удаление записи и закрытие по Escape.
   Убедитесь, что введённый пароль в истории отсутствует.
6. Откройте и закройте `nano` или `vim`: внутри программы подсказки не должны
   перекрывать управление, а после выхода должны снова работать.
7. Вызовите **Reload** для внутренней страницы терминала: экран и приглашение
   активной SSH-сессии должны восстановиться без отключения.
8. Откройте самостоятельный пункт **Терминал** в боковом меню. Создайте вторую
   вкладку, подключите её независимо, переименуйте и проверьте горизонтальное,
   вертикальное разделение и сетку из трёх-четырёх панелей. Отключение одной
   вкладки не должно завершать другую.
9. Для второй вкладки выберите другой сохранённый SSH-профиль. Затем проверьте
   временное подключение по `login`, `hostname` и нестандартному порту. Адреса
   в двух панелях и их приглашения должны отличаться.
10. Добавьте команду в избранное и создайте шаблон
   `sudo systemctl restart ${service}`. При вставке должно запрашиваться только
   значение `service`, без автоматического запуска команды.
11. В активной SSH-сессии обновите команды сервера и проверьте вкладку
    **Сервер**: обнаруженные службы и контейнеры должны появиться без изменения
    их состояния.
12. Для нового ключа нажмите **Создать ключ…**, выберите Ed25519 или RSA 4096,
   путь и введите passphrase в отдельном встроенном терминале. Основную
   SSH-сессию завершать не требуется.
13. Выберите созданный ключ и нажмите **Установить на сервер**. Введите текущий
   пароль сервера, затем переподключитесь по ключу.
14. Для SFTP и forwarding выберите ключ в профиле. Если системный `ssh-agent`
   недоступен приложению из Finder, Selective Remote автоматически создаст
   собственный агент и покажет безопасный запрос passphrase.

Selective Remote не хранит пароль SSH-сервера и не копирует приватный ключ.

## Проверка SFTP

1. Откройте самостоятельный раздел **SFTP** и нажмите **Подключить SFTP**.
2. Выберите сохранённый профиль либо вручную укажите hostname/IP, логин и порт.
   Для парольного сервера проверьте отдельный защищённый запрос пароля.
3. Убедитесь, что слева показан локальный Mac, а справа — удалённый сервер.
4. Перетащите тестовый файл и папку слева направо, затем обратно.
5. Перетащите файл из Finder в удалённую панель.
6. Перетащите удалённый файл из Selective Remote в папку Finder.
7. Проверьте кнопки назад/вперёд, хлебные крошки и переход по пути из адресной
   строки в обеих панелях.
8. Нажмите заголовки **Имя**, **Владелец**, **Доступ**, **Изменён** и **Размер**, затем
   проверьте остальные варианты через меню сортировки.
9. Щёлкните правой кнопкой по пустому месту обеих панелей и создайте тестовые
   файл и папку; затем проверьте фильтр по имени.
10. Правым кликом откройте свойства файла, измените тестовый режим доступа
   галочками, переименуйте файл и откройте текстовый файл во встроенном редакторе.
11. Перейдите из SFTP в терминал и обратно: каталоги и подключение должны сохраниться.
12. Удалите локальный тестовый файл в Корзину; серверное удаление проверяйте
    только на специально созданном тестовом объекте.
13. Добавьте несколько файлов в очередь, поставьте текущий на паузу, перейдите в
    терминал и вернитесь; очередь и прогресс должны сохраниться. Затем проверьте
    отмену и повтор частично переданного файла.

SFTP использует выбранный ключ, системный/резервный `ssh-agent`, control socket
уже аутентифицированной встроенной SSH-сессии либо отдельный защищённый запрос
пароля/passphrase. Пароль SSH-сервера приложение не сохраняет.

## Проверка port forwarding

1. Откройте самостоятельный пункт **Forwarding** в боковом меню.
2. Добавьте локальное, удалённое или SOCKS-правило.
3. Выберите для правила сохранённый SSH-профиль или ручной адрес. Для ручного
   адреса заранее настройте ключ, ssh-agent либо `~/.ssh/config`.
4. Заполните listening address/port и, кроме SOCKS, конечный host/port.
5. Нажмите **Запустить**.
6. После проверки остановите правило; при ошибке откройте его журнал.

Каждое правило использует отдельный SSH-процесс и не завершается при наличии
активного терминала или SFTP-сессии. Активные туннели завершаются вместе с
Selective Remote. Удалить SSH-профиль с работающим туннелем нельзя.

## Важное ограничение среды сборки

Полную сборку выполняйте на macOS с Xcode, Homebrew, FreeRDP 3.x и SDL3.
Скрипт запускает Swift-тесты и нативные тесты, включая детерминированную
двунаправленную проверку PTY без внешних диалогов. Аргументы `ssh-keygen`
проверяются отдельным Swift-тестом. Затем скрипт проверяет переносимость
библиотек, подписывает основной bundle, RDP helper и SSH askpass-helper и создаёт
Drag & Drop DMG.
