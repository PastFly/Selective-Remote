# Поддержка

- Ошибка приложения: создайте **Bug report** в GitHub Issues.
- Идея или улучшение: создайте **Feature request**.
- Уязвимость: следуйте [SECURITY.md](SECURITY.md).

Перед отправкой журнала удалите имена пользователей, IP-адреса, DNS-имена,
пути домашнего каталога и другую информацию о вашей инфраструктуре. Никогда не
прикладывайте пароли, токены и приватные SSH-ключи.
