# Selective Remote 0.32.0 — minimal community candidate

This branch intentionally starts at the **published v0.31.0 source commit** `0db37beb06051c2a519888bc0afa7cfaee22de32`, not unreleased `main` and not PR #224.

Only the version/build, bilingual release notes, and bounded local double-click host activation are changed. The official Cloud V1/V2/Teams launch remains excluded. The 0.31 backup and local storage implementations are retained without the unaccepted 0.32 migration.

## Release rules

- This is **ad-hoc signed, not Developer ID signed or notarized**.
- The pinned exact-SHA GitHub CI produces a verified test DMG. A separate guarded workflow may publish it as **v0.32.0-community.1 prerelease**, never as the official signed release. The update feed remains on v0.31.0.
- Real macOS smoke acceptance is still required before claiming that double-click behavior is validated.
- Do not deploy Cloud, change production registration or migrate Vaults from this branch.
- Keep `Resources/updates.json` on the last approved stable version v0.31.0.
- Do not merge this divergent release branch into `main`; its purpose is to ship a limited, independent build without importing incomplete 0.32 features.
- PR #224 and PR #228 remain untouched.

## Acceptance

CI: Swift tests, release build, DMG checksum, image integrity and code-sign verification.

Manual macOS checks: local SSH/RDP profile selection by single click, activation by double click, profile persistence, Keychain, encrypted backup/restore and clean launch. A successful CI does not replace these tests.
