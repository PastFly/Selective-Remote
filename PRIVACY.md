# Конфиденциальность и разрешения macOS

Selective Remote работает локально и не отправляет профили разработчикам
проекта. Пароли RDP и шлюза, а также секреты SSH хранятся в macOS Keychain.
Экспорт профилей не включает пароли и приватные SSH-ключи.

## Необязательные разрешения

- **Микрофон** — только для перенаправления звука с Mac в Windows.
- **Камера** — только для перенаправления выбранной камеры в Windows.
- **Файлы и папки** — только для выбранных перенаправляемых папок и локальной
  панели SFTP.

Отказ от микрофона, камеры или папки отключает соответствующий канал, но не
должен препятствовать обычному RDP-подключению.

## Сетевые соединения

Приложение подключается к адресам RDP/SSH/SFTP и шлюзам, которые указал
пользователь. Проверка обновлений выполняется только при наличии настроенного
URL ленты обновлений.

## Журналы

Журналы сессий сохраняются локально для диагностики и могут содержать адреса
серверов, имена устройств и системные пути. Перед публикацией журнала удалите
эти данные.
