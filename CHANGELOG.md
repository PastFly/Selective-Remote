# История изменений Selective Remote

[← Вернуться на главную страницу](README.md)

## 0.17.4

- SSH-терминал сохраняет историю выполненных команд отдельно для каждого
  профиля и восстанавливает её после перезапуска приложения;
- при вводе команды возле курсора появляются подходящие варианты из истории;
  стрелки выбирают вариант, Enter подставляет его в строку без немедленного
  запуска, а Escape закрывает список;
- добавлена отдельная панель истории с поиском, повторной подстановкой,
  удалением отдельных записей, полной очисткой и отключением сохранения;
- история хранится только локально, ограничена по объёму и не записывает строки
  с пробелом в начале, распространёнными признаками секретов или вводом без эха;
- подсказки автоматически скрываются в полноэкранных терминальных программах,
  чтобы не перехватывать их управление.

## 0.17.3

- кнопка оформления больше не становится визуально выбранной сразу после
  запуска приложения;


## 0.17.2

- в ARM64-DMG добавлен OpenSSL `legacy.dylib`, содержащий MD4 для
  NTLM/CredSSP-аутентификации FreeRDP;
- RDP-процесс получает `OPENSSL_MODULES`, указывающий на провайдер внутри
  `Selective Remote Session.app`, и больше не зависит от Homebrew на Mac
  пользователя;
- production-сборка проверяет переносимость и подпись провайдера, а финальный
  smoke-тест отклоняет DMG при сообщениях `LEGACY provider failed` или
  `NTLM support not available`;
- публичная версия теперь отображается без внутреннего `CFBundleVersion`;
- окно обновлений получило кнопку **Что нового**;
- каждый выпуск публикуется под новым тегом как отдельный стабильный Release,
  отмеченный **Latest**; повторное использование существующего Release
  блокируется workflow.

## Добавлено в Productivity v9

- SFTP получил постоянную очередь передач: отдельный прогресс и скорость для
  каждого объекта, паузу, продолжение, отмену, повтор с `reget`/`reput`, а также
  правила конфликтов **сохранить оба / заменить / пропустить**; очередь не

- добавлена плавающая панель активных RDP-сессий, доступная поверх полноэкранных

  полный экран/окно, переподключение и отключение;
- звук, микрофон и камера меняются из панели и безопасно применяются автоматическим

- правила клавиатуры теперь настраиваются по профилю: Command→Ctrl,
  правый Command→Windows, Option→Windows, Fn→Win+Space и собственные
  переназначения служебных клавиш;
- добавлены фиксированное окно и окно с динамическим разрешением FreeRDP;
- меню macOS показывает избранные профили для быстрого подключения, команды
  активных RDP-сессий и управление SFTP-передачами;
- управление RDP передаётся отдельному процессу через приватный FIFO и штатную
  очередь SDL; внутренние функции FreeRDP по-прежнему не перехватываются;
- версия приложения: **0.17.1 (build 63)**.

## Добавлено в Fn/permissions v8

- одиночное нажатие **Fn** в активном RDP-окне отправляет **Win+Space** и
  переключает раскладку Windows; сочетания Fn с другими клавишами не запускают
  переключение;
- новый Fn-модуль не перехватывает функции FreeRDP: он добавляет обычные
  клавиатурные события в штатную очередь SDL, а сборка отдельно запрещает
  появление таблицы FreeRDP/DYLD interpose в этом модуле;
- отказ macOS в доступе к микрофону или камере больше не завершает RDP-процесс:
  подключение продолжается без соответствующего канала;
- недоступные папки не передаются в Windows и не мешают запуску рабочего стола;
- версия приложения: **0.17.1 (build 62)**.

## Исправлено в патче Retina/keyboard v4

- смешанная связка Full HD + Retina больше не применяет глобальный
  `FREERDP_WLROOTS_HACK` к настоящим окнам RDP: скрытые monitor-probe получают
  логические размеры отдельно, а полноэкранные окна сохраняют собственную
  плотность пикселей каждого дисплея;
- добавлен профильный переключатель **Использовать ⌘ как Ctrl в Windows**,
  включённый по умолчанию; обе клавиши Command передаются как Ctrl, поэтому
  ⌘C/⌘V/⌘X/⌘A работают привычным для macOS способом;
- старые профили автоматически получают новое поведение, а переключатель можно
  отключить, чтобы снова передавать Command как клавишу Windows.

**Selective Remote** — самостоятельное нативное приложение macOS для RDP-, SSH-
и SFTP-профилей. RDP поддерживает визуальный выбор произвольного набора
физических дисплеев, а SSH — встроенный терминал, двухпанельный SFTP, системные
ключи и port forwarding. Пакет приложения называется `Selective Remote.app`,
исполняемый файл и служебные артефакты используют единое имя `SelectiveRemote`.

## Исправлено в 0.17.1

- завершено внутреннее переименование: `.app`, bundle identifiers, исполняемые
  файлы, helpers, журналы и настройки больше не используют прежнее имя;
- SFTP сохраняет подключение, текущие каталоги и фильтры при переходе между
  вкладками **SFTP** и **Терминал**;
- добавлены фильтры по имени, видимый столбец даты изменения, создание пустых
  файлов и папок через контекстное меню пустой области;
- одиночный щелчок явно выделяет файлы и папки, а редактор POSIX-прав получил
  понятные галочки чтения, записи и выполнения для владельца, группы и остальных;
- перенос удалённых файлов и папок использует ленивое файловое представление
  штатного `NSItemProvider`, совместимое со SwiftUI drag-and-drop;
- устранена ложная надпись «Удалённая папка пуста», когда OpenSSH возвращает
  непустой каталог в варианте `ls -l`, отличающемся от прежнего строгого шаблона;
- SFTP-парсер теперь принимает числовой или неизвестный link count, UID/GID
  вместо имён, ACL-маркеры, ведущие пробелы, локализованные месяцы, традиционную
  и ISO-дату, сохраняя пробелы в именах файлов; полные пути из ответа OpenSSH
  корректно приводятся к именам объектов текущего каталога;
- если будущая версия сервера вернёт действительно неизвестный формат,
  приложение покажет диагностическую ошибку с безопасным фрагментом ответа,
  а не выдаст непустую папку за пустую;
- добавлены регрессионные тесты на каталог Debian `/etc`, приглашение OpenSSH,
  ACL-маркеры, неизвестный link count и ISO-дату;
- версия приложения: **0.17.1 (build 58)**.

## Добавлено и изменено в 0.17.0

- SFTP превращён в полноценный двухпанельный проводник: появились история
  **назад/вперёд**, кликабельные хлебные крошки и адресная строка для прямого
  перехода к локальному или серверному пути;
- в списках сразу видны владелец с группой, символьные POSIX-права и размер;
  сортировка работает по имени, размеру, дате изменения, владельцу и доступу,
  папки при этом остаются сверху;
- правый клик открывает контекстное меню: открыть, открыть с помощью, встроенно
  редактировать удалённый UTF-8-файл, скопировать между панелями, переименовать,
  показать в Finder, удалить и открыть свойства;
- окно свойств показывает полный путь, тип, размер, дату, владельца, группу,
  символьный и восьмеричный режим; из него можно выполнить `chmod`, а при наличии
  серверных прав — сменить UID/GID через `chown` и `chgrp`;
- локальное удаление отправляет объект в Корзину; серверное удаление требует
  отдельного подтверждения и для папок допускается только при пустом каталоге;
- встроенный редактор ограничен текстовыми UTF-8-файлами до 5 МБ и при сохранении
  не переносит права временного файла на сервер;
- начат совместимый ребрендинг: видимое имя — **Selective Remote**, подпись —
  **RDP · SSH · SFTP**, акцент смещён к сине-бирюзовой палитре и сетевому знаку;
- версия приложения: **0.17.0 (build 57)**.

## Добавлено и исправлено в 0.15.0

- терминал больше не находится внутри ограниченного `ScrollView`: он растягивается на всю доступную ширину и высоту окна;
- кнопка **Развернуть терминал** включает режим «Фокус»: скрываются боковая панель, заголовок профиля, вкладки и нижняя строка; повторное нажатие или `⌘⇧Enter` возвращает интерфейс;
- размер xterm пересчитывается после фактической раскладки SwiftUI/WKWebView и изменения шрифта, а PTY получает стабильные столбцы и строки;
- промежуточная геометрия `2×1`, возникающая во время переключения вкладок, больше не передаётся `nano`, `vim`, `tmux` и другим TUI-программам;
- ANSI/VT-вывод передаётся в WebView строго по порядку небольшими блоками и последовательно разбирается xterm.js; это устраняет повреждение полноэкранной разметки и цветов;
- локальная CSP терминала разрешает динамические стили, которые xterm.js 6 использует для canvas/DOM-геометрии; скрипты и внешняя сеть остаются запрещены;
- в панели **Оформление** доступны темы Midnight, Hacker Green, Solarized Dark, Dracula, Light и пользовательская тема;
- настраиваются фон, цвет текста, курсор, шрифт, размер, межстрочный интервал, форма и мигание курсора, внутренний отступ;
- настройки терминала сохраняются для следующих запусков и применяются также к отдельному терминалу генерации SSH-ключа;
- строка состояния терминала показывает фактический размер PTY в столбцах и строках;
- системное хранилище ключей ищется через LaunchServices по bundle identifier, затем по путям Keychain Access для разных macOS; при отсутствии отдельной «Связки ключей» используется приложение «Пароли»;
- отсутствие внешнего GUI хранилища больше не выдаётся за неисправность Keychain: SSH-ключами SelectiveRemote можно управлять во встроенном окне;
- версия приложения: **0.15.0 (build 53)**.

## Добавлено и исправлено в 0.14.0

- SFTP получил двухпанельный файловый менеджер: слева локальный Mac, справа удалённый сервер;
- файлы и папки можно переносить между панелями кнопками или drag-and-drop, включая загрузку из Finder и экспорт удалённых объектов обратно в Finder;
- для удалённых папок используются рекурсивные операции SFTP, а новые локальные копии получают безопасное свободное имя вместо незаметной перезаписи;
- локальная панель умеет переходить домой, вверх, в выбранную через системный диалог папку, обновляться и создавать каталоги;
- SFTP и port forwarding могут повторно использовать уже аутентифицированную парольную SSH-сессию через отдельный защищённый OpenSSH control socket; пароль по-прежнему не сохраняется;
- сокет привязан к профилю, host, пользователю и порту, поэтому после изменения подключения старая сессия не будет использована для другого сервера;
- генерация SSH-ключа выполняется в отдельном встроенном PTY и больше не требует завершать текущую SSH-сессию;
- добавлены регрессионные тесты multiplexing и рекурсивных команд SFTP;
- версия приложения: **0.14.0 (build 51)**.
