# Политика безопасности

## Поддерживаемая версия

Исправления безопасности выпускаются для последней опубликованной версии
Selective Remote.

## Сообщение об уязвимости

Не создавайте публичный issue с рабочим эксплойтом, паролями, ключами,
внутренними адресами или журналами реальной инфраструктуры.

Используйте **Security → Report a vulnerability** в репозитории GitHub. Если
Private vulnerability reporting ещё не включён, создайте обычный issue без
технических деталей с просьбой открыть приватный канал связи.

Укажите версию macOS, версию Selective Remote, версию FreeRDP, ожидаемое и
фактическое поведение и минимальные безопасные шаги воспроизведения.
