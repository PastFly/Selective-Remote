# Product capture provenance

The original eight scene images are window-only captures from an isolated copy of the Selective Remote 0.32.0 (163) candidate on macOS. The public download remains v0.31.0. All four views were captured separately in the app's Russian and English modes.

The capture profile contains four synthetic hosts with reserved `.example` names and the test username `demo`. The SFTP source contains only test files under a temporary demo directory. No real Personal Vault or Team Vault data, credentials, corporate addresses, or production connections were used.

The eight scene files are actual app UI: Hosts, Terminal, SFTP, and Snippets in each language. The service window title was cropped from every capture. The SFTP file-owner values, which macOS supplies from the local account, were masked in the file rows. No UI text was added or redrawn. Two smaller `hosts-hero` files are resampled derivatives of the corresponding full-resolution Hosts captures.

The Terminal capture shows a stopped local shell and the SFTP capture has no connected server. Those states are described beside the images on the page. Some controls inside the 0.32 candidate remain untranslated in English mode; the captures preserve the actual interface.

The two `rdp-displays` captures were supplied by the Owner from the 0.32 candidate. They show the same synthetic `.example` host names and a two-display RDP profile in RU and EN. Only the capture window's title bar was cropped; no app UI text was changed. Visual privacy review found no credentials, usernames, private paths, real hostnames, IP addresses, or production Vault data. The visible monitor model and display dimensions describe the demo capture hardware. Some display labels remain in Russian in the EN candidate capture.
