← Selective Remote

Multi-monitor RDP on macOS with Retina support

Selective Remote is an open-source RDP client for macOS built around SDL-FreeRDP. It supports true macOS fullscreen, Retina-aware rendering, selected multi-monitor sessions, external displays, manual monitor layout, RDP Gateway and Smart Reconnect.

Typical workflow

  1. Create or open an RDP profile.
  2. Select fullscreen or windowed mode.
  3. Choose the displays that should participate.
  4. Adjust monitor layout when needed.
  5. Connect and use the macOS fullscreen/menu behavior normally.
