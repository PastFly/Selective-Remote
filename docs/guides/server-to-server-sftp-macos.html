← Selective Remote

Server-to-Server SFTP transfers on macOS

Selective Remote includes a dual-pane SFTP Workspace where either pane can be the local Mac, a saved SSH profile, or a temporary SSH/SFTP server.

How Server → Server works

Selective Remote does not pass one server's credentials to the other. The transfer uses a temporary restricted staging copy on the Mac: Server A → Mac → Server B. Temporary data is cleaned up after the transfer.

Workflow

  1. Select Server A and Server B in the two panes.
  2. Select files or folders.
  3. Drag them to the destination pane.
  4. Follow both transfer stages in Transfer Queue with bytes, percentage, speed and ETA.
