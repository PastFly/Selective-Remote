ОДНО ПРОСТРАНСТВО

Для личной работы и команды

Selective Remote объединяет подключения и автоматизацию, не заставляя отдавать серверу ключи от вашей инфраструктуры.

01

Personal Vault

Hosts, пароли, SSH-настройки и Snippets синхронизируются между вашими устройствами.

02

Team Workspace

Общие Vaults, папки, роли и приглашения для безопасной совместной работы.

03

Локальный режим

Cloud остаётся дополнением: приложение продолжает полноценно работать автономно.

ОДНО ДЕЙСТВИЕ · ДВА УСТРОЙСТВА

Создали Host на Mac.
Продолжили в браузере.

Открытый профиль не покидает ваше устройство: в Cloud отправляется только зашифрованная ревизия, которую второе доверенное устройство расшифровывает локально.

  1. ＋
    ШАГ 01 · macOSСоздаёте Host

    Адрес, папка и настройки подключения сохраняются в вашем Vault.

  2. ◇
    ШАГ 02 · E2EEУстройство шифрует

    Cloud получает новую версию ciphertext, но не Host и не его Credentials.

  3. ✓
    ШАГ 03 · BrowserHost появляется рядом

    Доверенный браузер получает ревизию и открывает её своим локальным ключом.
